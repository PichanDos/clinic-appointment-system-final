# ระบบนัดหมายคลินิก

ระบบตัวอย่างตามโจทย์ทดสอบสำหรับจัดการผู้ป่วย นัดหมาย รายการนัดรายวัน และรายงานสรุป เขียนด้วย PHP 8.2, PDO, MySQL/MariaDB และ CSS โดยไม่ใช้ framework เพื่อให้ติดตั้งและอธิบายโค้ดได้ง่าย

## แผนงานและขอบเขต

1. ออกแบบตาราง `patients`, `doctors`, `appointments` พร้อม foreign key และ index
2. ทำการลงทะเบียน แก้ไข ค้นหาผู้ป่วย และสร้าง HN อัตโนมัติ
3. ทำการจอง ตรวจเวลาซ้อน แสดงรายการนัด และเปลี่ยนสถานะ
4. ทำรายงานตามช่วงวันที่

## ติดตั้งและรัน

ต้องมี PHP 8.2+ พร้อม `pdo_mysql`, `mbstring`, MySQL 8 หรือ MariaDB 10.4+ และเปิดฐานข้อมูลอยู่

1. นำเข้า `database/schema.sql` แล้ว `database/seed.sql` ด้วย phpMyAdmin หรือ MySQL CLI; หากต้องการข้อมูลผู้ป่วยและนัดหมายสำหรับสาธิต ให้นำเข้า `database/demo.sql` อีกครั้งหนึ่ง
2. คัดลอก `config.example.php` เป็น `config.local.php` แล้วแก้ host, port, database, username และ password ตามเครื่อง (ไฟล์นี้ไม่ถูก commit)
3. จากโฟลเดอร์โครงการ รัน `php -S 127.0.0.1:8765 -t public`
4. เปิด `http://127.0.0.1:8765`

ตัวอย่างสำหรับ XAMPP: เปิด MySQL ใน XAMPP Control Panel, นำเข้า SQL ใน phpMyAdmin แล้วใช้ค่าฐานข้อมูลใน `config.example.php` หาก root ไม่มีรหัสผ่าน

**ข้อมูลตัวอย่าง:** `seed.sql` เพิ่มแพทย์ 4 คนแบบรันซ้ำได้ ส่วน `demo.sql` เพิ่มผู้ป่วย 2 คนและนัดหมาย 3 รายการสำหรับการสาธิต ให้รัน `demo.sql` เพียงครั้งเดียวเพราะรันซ้ำจะเพิ่มข้อมูลอีกชุด

## วิธีใช้งาน

- **ผู้ป่วย:** กรอกชื่อ นามสกุล เบอร์มือถือ และวันเกิด ระบบสร้าง `HN000001` ต่อเนื่องตาม ID ที่ฐานข้อมูลออกให้ ค้นหาด้วยชื่อ HN หรือเบอร์โทร และกดแก้ไขในตาราง
- **นัดหมาย:** ค้นหาผู้ป่วย เลือกผู้ป่วย แพทย์ วัน และเวลาเริ่ม/สิ้นสุด กดบันทึก จากนั้นกรองรายการตามวัน/แพทย์และเปลี่ยนสถานะ
- **ภาพรวมวันนี้:** ดูจำนวนและรายการนัดของวันนี้ตามเวลา
- **รายงาน:** เลือกช่วงวันเพื่อดูจำนวนผู้ป่วยใหม่ จำนวนรายการนัดทั้งหมด และแยกสถานะ

## การออกแบบฐานข้อมูล

| ตาราง | หน้าที่ | Index สำคัญ |
| --- | --- | --- |
| `patients` | ข้อมูลผู้ป่วย เลข HN ไม่ซ้ำ | `hn` unique, ชื่อ, เบอร์โทร, วันลงทะเบียน |
| `doctors` | รายชื่อแพทย์ตัวอย่าง | primary key |
| `appointments` | นัดหมายและสถานะ | `(doctor_id, appointment_date, status, start_time, end_time)` สำหรับตรวจเวลาซ้อน, `(appointment_date, status)` สำหรับรายการ/รายงาน |

เวลา `10:00–11:00` และ `10:30–11:30` ถือว่าซ้อนกัน แต่ `10:00–11:00` และ `11:00–12:00` ไม่ซ้อนกัน การสร้างนัดและคืนสถานะนัดที่ยกเลิกจะล็อกแถวของแพทย์ก่อนตรวจชน เพื่อป้องกันคำขอสองรายการจองพร้อมกันแล้วผ่านทั้งคู่ นัดที่ยกเลิกไม่กันเวลาไว้

เบอร์โทรจะเก็บเป็นตัวเลข 10 หลักแบบ `0812345678` โดยรองรับ `081-234-5678`, `+66812345678` และ `66 81 234 5678` แบบเดียวกัน สถานะในฐานข้อมูลใช้ `pending`, `arrived`, `cancelled`

รายงานนับ **ผู้ป่วยใหม่** จาก `registered_at` และนับ **นัดหมายทั้งหมด** จาก `appointment_date` ตามช่วงวันที่ที่เลือก รวมรายการยกเลิกด้วย จากนั้นแยกตามสถานะ ช่วงเวลารวมวันต้นและวันสุดท้าย วิธีนี้เหมาะกับข้อมูลจำนวนมากเพราะใช้ `COUNT`/`GROUP BY` ในฐานข้อมูล ไม่ดึงทุกแถวเข้าหน่วยความจำ

## ทดสอบ

```powershell
php tests/unit.php
php tests/integration.php
Get-ChildItem -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
```

Integration test ต้องเชื่อมต่อฐานข้อมูลที่ตั้งค่าไว้และมีแพทย์จาก `seed.sql` ทดสอบการสร้าง/แก้ไขผู้ป่วย, normalize เบอร์, จองซ้อน, แพทย์ต่างคน, ยกเลิกแล้วจองใหม่, ห้ามคืนสถานะหากชน, และยอดรายงาน โดยลบข้อมูลที่ใช้ทดสอบเมื่อจบ

## โครงสร้างโค้ด

- `public/index.php` รับ request, จัดการฟอร์ม, และแสดงแต่ละหน้า
- `public/assets/style.css` รูปแบบหน้าจอ responsive
- `src/bootstrap.php` การตั้งค่า, session, PDO
- `src/functions.php` ตรวจข้อมูล, CSRF, flash, escape HTML
- `src/repository.php` คำสั่งฐานข้อมูลและกฎธุรกิจ
- `database/` schema, รายชื่อแพทย์ และข้อมูลสาธิต
- `tests/` unit และ integration checks

## สิ่งที่อาจพัฒนาต่อ

- ยังไม่มีตารางเวลาทำงานแพทย์ การแจ้งเตือน หรือการแก้ไขวัน/เวลานัดโดยตรง; ใช้ยกเลิกแล้วสร้างนัดใหม่
